# Security

This repository is a portfolio. It describes private projects; it is not those projects, and it is not a place to put credentials.

## What should never be in this repo

- API keys, tokens, passwords, private keys, or `.env` files with values filled in
- A paper-trading ledger, alert chat IDs, or host/systemd configuration
- Email addresses, phone numbers, or other personal contact paths (the only public contact is GitHub: [VeinkWiles](https://github.com/VeinkWiles))
- Session URLs, workspace identifiers, or raw agent transcripts
- pawn-bench logs, raw `results/` files, or handoff notes
- Screenshots or videos of Xenimus, or side-by-side comparison images that include it

The published pawn-bench scripts expect local paths through environment variables, not hard-coded home directories.

## Paper trading

`paper-trading-runner` is a private prototype. It is paper-only. Live Alpaca keys are refused. Real-money trading is not built. Nothing in this portfolio authorizes, configures, or demonstrates live trading.

## Reporting a problem

If you find a credential or personal data in this repository, please open a [GitHub issue](https://github.com/VeinkWiles/applied-ai-portfolio/issues) or a security advisory on [this repository](https://github.com/VeinkWiles/applied-ai-portfolio), and do not redistribute the secret. I will rotate anything that was exposed.
