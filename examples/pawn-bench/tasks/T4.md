Benchmark task T4 (log-trimming script for agents).

Agents waste context reading long Godot logs. In <nextimus-pawn>, write `tools/godot_log_summary.py` (Python 3, standard library only):

Usage: `python3 tools/godot_log_summary.py <logfile>`

Output, in this order:
1. First line exactly `VERDICT: PASS` or `VERDICT: FAIL`.
2. `ok: <n>  fail: <n>` counting lines that start with `ok:` and lines that contain `FAIL:`.
3. Every line containing `SCRIPT ERROR`, each with the line after it.
4. Every `FAIL:` line, but at most 20, then `(+N more)` if there were more.

Verdict rules:
- FAIL if any line contains `SCRIPT ERROR`.
- Otherwise the LAST marker in the file decides: `ALL TESTS PASSED` or `PLAYTEST PASSED` means PASS; `PLAYTEST FAILED` or a line ending in ` FAILED` with a number before it (like `3 FAILED`) means FAIL.
- No marker at all means FAIL.
- Exit code 0 for PASS, 1 for FAIL.

Careful: a passing rule-test log contains `PT FAIL: timeout_hang timed out` and `PT PLAYTEST FAILED` from a self-test that is supposed to fail, BEFORE its final `ALL TESTS PASSED`. That log must be PASS.

Test it on the four logs in `<pawn-bench>/fixtures/`. Expected verdicts: `suite-pass.log` PASS, `suite-fail.log` FAIL, `playtest-pass.log` PASS, `playtest-script-error.log` FAIL. Do not edit the fixtures.
Done when all four give the expected verdict and exit code, and you have committed the script on the branch named below. Put each verdict and exit code in your TESTS line.
