# Synthetic checker fixture and harness status tests

These files exist so a reviewer can run the published stdlib checkers and the `run.sh` result handling without a private Nextimus checkout, without Quaternius Source packs, and without Blender.

The meshes are **invented**, generated by `generate_fixture.py`. They are **not** Quaternius art, **not** Nextimus assets, and **not** a pawn-bench task rerun. A passing fixture does not mean a T-task passed, and it is not a substitute for the 14 Nov 2026 overnight set.

The four `*.log` files in this folder (`suite-pass`, `suite-fail`, `playtest-pass`, `playtest-script-error`) are sanitized T4 fixtures for the log-summarizer task. They are real Godot log text with a private playtest-report path replaced by a placeholder. They are not agent transcripts.

## Coverage, by behavior

Checker fixture (`test_checkers.py`):

| Behavior | What is exercised |
|---|---|
| Good export | `glb_check.py` on a tiny skinned, textured box: 12 triangles / 1 surface, passes under a 20-triangle cap |
| Triangle budget | The same export fails a 4-triangle cap |
| Shape failure | A collapsed export fails the shape check |
| Missing skinning | An unskinned export fails the skinned check |
| Surface limit | A two-primitive export fails `--max-surfaces 1` |
| Corrupted input | A non-glTF file exits 1 with `FAIL  input` |
| Seams, coincident | `kit_check.seam_share`: 8 of 8 (100%, above the 85% floor) |
| Seams, cracked | A 5 mm shift: 0 of 8 (0%) |
| Seam threshold boundary | 34 of 40 (85%) meets `SEAM_MIN`; 32 of 40 (80%) fails it |
| Invalid manifest | `kit_check.py` rejects a JSON file that is not a kit manifest |
| Duplicate slot | `kit_loadout.py` refuses two pieces in the same slot |
| Source-art path | `kit_check.source_art_root` honors `QUATERNIUS_SOURCE`, with `KIT_SOURCES` as a fallback alias |

It does not run `pare_lib.py`, `night-1114.sh`, or any T1–T16 prompt against a real model. It does not validate preview images, texture resizing (optional Pillow), or hidden-hair loadouts end to end.

Harness status tests (`test_harness.sh`):

| Behavior | Expected `run.sh` result |
|---|---|
| Agent failure | `result=FAIL`, exit 1 |
| Missing outputs | `result=FAIL`, exit 1 |
| Checker failure | `result=FAIL`, exit 1 |
| Timeout | `result=TIMEOUT`, exit 124 |
| Infrastructure failure | `result=INFRA`, exit 75 |
| Success | `result=PASS`, exit 0 |
| Successful repair | `result=PASS`, exit 0, after one fix round |

Those tests invent a disposable git checkout, a mock `openclaw`, and stub checkers. They do not open the private game or source-art trees.

## How to run

From the repository root:

```bash
python3 examples/pawn-bench/fixtures/test_checkers.py
bash examples/pawn-bench/fixtures/test_harness.sh
```

The checker test regenerates the `.glb` files and then calls the checkers. Pillow is not required for this path.
