# Synthetic checker fixture

These files exist so a reviewer can run the published stdlib checkers without a private Nextimus checkout, without Quaternius Source packs, and without Blender.

They are **invented meshes**, generated by `generate_fixture.py`. They are **not** Quaternius art, **not** Nextimus assets, and **not** a pawn-bench task rerun. A passing fixture does not mean a T-task passed, and it is not a substitute for the 14 Nov 2026 overnight set.

## What it covers

- `glb_check.py` on a tiny skinned, textured box: a 12-triangle export that passes under a 20-triangle cap, fails a 4-triangle cap, and fails a shape check when the export is collapsed.
- `kit_check.seam_share` on two open body regions: coincident edges score 8 of 8 (100%, above the 85% floor); a 5 mm shift scores 0 of 8 (0%).

It does not run `pare_lib.py`, `run.sh`, or any T1–T16 prompt.

## How to run

From the repository root:

```bash
python3 examples/pawn-bench/fixtures/test_checkers.py
```

The test script regenerates the `.glb` files and then calls the checkers. A recorded local run on 19 Nov 2026, America/Chicago (CST), printed `ALL FIXTURE TESTS PASS` after:

- `glb_check` good export, 12 triangles / 1 surface, `ALL CHECKS PASS` (exit 0)
- the same export under a 4-triangle cap, `FAIL  budget` (exit 1)
- a collapsed export, `FAIL  shape` (exit 1)
- coincident seams 8 of 8 (100%); cracked seams 0 of 8 (0%)
